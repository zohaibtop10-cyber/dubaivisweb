# Separate Buildings v2 — closer to the hero image

Each file is its own .glb, centred at x = z = 0, standing on y = 0.
These are front-view reconstructions traced from enlarged crops of the
512x218 hero image, not the earlier stylised versions.

## What changed from v1
- Burj Khalifa: 10 slender tiers (was 5), pink band at every setback,
  vertical window columns, narrower base (2.0 wide, 22.0 tall).
- Museum of the Future: thinner ring (major 4.2, minor 0.78) tilted back
  50 degrees, so from the front it is a wide oval (torus ~9.9 wide,
  ~5.4 tall in front view) with an elliptical hole, denser calligraphy
  texture with a purple lower tint, dark hill only (no rectangular base).
  File width 12.4 includes the wide hill; the torus itself is 9.9 wide.
- Burj Al Arab: taller, narrower curved sail (12.2 tall, max width 3.0),
  left side bulging, top point offset right, horizontal helipad platform
  at ~8.9 (was a disc), vertical ribs, blue-white-purple front texture.
- Skyline: 8 distinct silhouettes — flat with pink top, stepped, tall flat,
  medium with pink top, pointed, tapered (3 tiers), antenna, frame/bridge
  (two slabs + top bridge, as seen centre-right), and cylindrical.

## Honest limit
The source image is only 512 x 218 pixels, so each building is roughly
20-60 pixels wide in it. That image cannot show exact window counts, the
back sides, or the readable calligraphy text on the Museum. A literally
exact 1:1 3D copy cannot be recovered from that one flat image alone.
These v2 files are the closest front-view match that image supports,
using the real buildings' known shapes where the image is too small to
resolve detail. If you have a higher-resolution image, or front/side/back
photos of a building, send them and that building can be tightened further.
